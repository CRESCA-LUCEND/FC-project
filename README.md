# Fizzy & Crush asset pack

Everything Lovable needs to build the Fizzy & Crush site lives in `Assetpack/`.
Start with `Assetpack/LOVABLE_PROMPT.md`; the web-ready files (GLB cans, WebP renders, fonts) are in `Assetpack/web/`.

The full-resolution PNG render masters (25–60 MB each) are kept off the repo; the WebP files in `web/` are the versions to use on the site.
